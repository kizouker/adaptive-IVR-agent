Tired of waiting on hold with robot operators? Meet Holdmate.

Holdmate is an adaptive IVR agent that learns to phone robot lines like Sweden's Public Employment Service for you. It practices safely on AF Agda, a scripted copy of the real line built from recorded calls, so the real line is never touched during training.

- Talk mode: speak, Agda answers (Swedish voices), every turn lands on a live React board
- Learns: BFS lessons + teachable word aliases, map grows with every call
- Device day: queue ticket mirrors to iPhone and Watch over LAN

Repo: https://github.com/kizouker/adaptive-IVR-agent

Feedback wanted: what IVR line should Holdmate learn next? Try `./start.sh` and tell us how Agda did.
