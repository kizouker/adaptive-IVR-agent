## Slutsats

Negativt resultat på målklippet: byt inte STT ännu. Muse Voice avstår
korrekt där whisper hallucinerar; direkt-API:t gick inte att prova med
repots nyckel (401). README får därför ingen STT-modellrad (uppgift 4).

## Endpoint och format (Metas quickstart/API-ref)

- Fil: `POST https://api.meta.ai/v1/asr/transcribe`, multipart:
  `request={"model":"muse-voice-transcribe-1.0","audioEncoding":"WAV","mode":"PUSH_TO_TALK"};type=application/json`
  plus `audio=@fil.wav;type=audio/wav`, `Authorization: Bearer $MODEL_API_KEY`.
- Live: `wss://api.meta.ai/v1/asr/realtime` (samma modell).
- Källa: dev.meta.ai `/docs/api-reference/voice/transcribe` och
  `/docs/cookbook/voice-api-fundamentals` (läst 2026-11-04).
