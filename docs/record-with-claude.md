## Record with claude dictation

1. Start dictation in claude, to let claude transcribe your call in realtime. Post the dictation intermediately so you don't loose it if you fiddle with fingers etc.
2. Change settings on iphone to start on speaker mode
3. Call with your phone 
4. After the call let claude describe the call, make a graph in mermaid to describe the flow and the sections in the phonecall
5. Save the transcript and analysis in ```data/call-transcripts-by-claude```



## Configuration of the iphone
On iPhone you can make every call start on the loudspeaker:

1. Open Settings
2. Tap Accessibility
3. Tap Touch
4. Tap Call Audio Routing
5. Choose Speaker
